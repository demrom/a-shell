# CBC for a-Shell

The full app already embeds `xcfs/.build/artifacts/xcfs/cbc.framework` and loads `main` from `cbc.framework/cbc`. The mini and noPython targets do not embed it. `xcfs/Package.swift` does not currently provide the framework.

Run `scripts/build-cbc.sh` from the repository with Xcode and an installed iOS Simulator runtime that supports iPhone 17, `pkg-config`, and `jq`. If the checkout path contains spaces, pass a build directory without spaces, for example `scripts/build-cbc.sh /tmp/cbc-build`. The script downloads the releases in `sources.txt`, verifies the checksums, applies `patches/*.patch`, and builds the COIN-OR libraries statically into the command framework. It uses the pinned `ios_system` release already referenced by `xcfs/Package.swift`. The regular CBC CLI is retained; optional BLAS, readline, and parallel CBC are disabled. The command uses the shell's streams, does not install process-wide signal handlers, and exits the command thread rather than the app.

A successful build prints an `Artifacts:` path to a new directory containing `cbc.xcframework.zip`, `checksums.txt`, and `cbc-smoke.log`. The ZIP has an arm64 iOS device slice and an arm64/x86_64 iOS Simulator slice. The smoke test installs a Simulator app embedding the archived framework and loads it through `ios_system` and the a-Shell command dictionary. It checks that an unsupported MPS marker fails the command without terminating the process, then solves the same LP from a file and from redirected input in that process. The expected solution is `x = 2`, `y = 2`, with objective `10`. The device slice is built but not executed by this test.

The `CBC framework` workflow runs the same command. Before that workflow is on the default branch, pushing the candidate to `ci/cbc-framework` in the CI fork triggers it. For app integration, publish the verified ZIP and checksum and add its `binaryTarget` to the manifest; the command dictionary and the full app's embed path are unchanged. To roll back the producer, revert the recipe commit; the producer does not change app downloads or builds.
