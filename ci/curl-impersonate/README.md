# curl-impersonate iOS command

Run `ci/build-curl-impersonate.sh [build-directory]` from the repository root on a Mac with Xcode, CMake, and Ninja. The default build directory is `.build/curl-impersonate`. The same entry point runs on GitHub Actions; select Xcode locally with `DEVELOPER_DIR` if needed.

The recipe builds curl-impersonate 2.3.0 from source. Its upstream CMake superbuild pins curl 8.23.0, BoringSSL, c-ares, nghttp2, nghttp3, ngtcp2, Brotli, zlib, and Zstandard by SHA-256. The port links those libraries statically inside the command framework. It links against the ios_system 3.0.5 ABI without redistributing ios_system. Python's `curl_cffi` wrapper is a separate binary and does not link to the command framework.

The `dist/` directory contains `curl-impersonate.xcframework.zip`, `checksums.txt`, and the architecture and platform audit `slices.txt`. The ZIP contains an iOS arm64 slice and a universal arm64/x86_64 Simulator slice. For a local app build, verify the checksum and unpack the ZIP under `xcfs/.build/artifacts/xcfs/curl-impersonate/`; the full and mini targets embed the slice Xcode selects. To roll back a staged update, verify and unpack the previous compatible XCFramework in the same location. To undo the integration, revert the framework reference and command registration together and restore the original `xcfs/.build/artifacts/xcfs/curl-impersonate.framework`. A published release can replace manual staging with a SwiftPM binary target at the same path.

To exercise the packaged command through ios_system and the mini command dictionary, run `ci/curl-impersonate/smoke.sh .build/curl-impersonate BOOTED_SIMULATOR_UDID`. The smoke checks an invalid option, verifies that repeated calls on the same thread start with URL index zero and a fresh parallel progress meter, and runs two HTTPS requests to https://example.com with a-Shell's bundled CA file. Both requests must return HTTP 200 and exit status 0. An explicitly configured missing CA file must fail. The smoke does not need a full a-Shell build.
